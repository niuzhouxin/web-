## 基本指令
- `ls`:查看当前文件夹下的内容，加`-a`，表示显示所有内容，包括隐藏文件，加`-l`表示以列表的形式列出文件
- `pwd`:查看当前所在文件夹
- `cd[目录名]`:切换文件夹，`cd ..` 切换到上一级目录
- `touch[文件名]`如果**文件不存在**，新建文件,如果文件已存在，`touch` 会默认更新其 **访问时间（atime）** 和 **修改时间（mtime）** 为当前系统时间。
- `mkdir[目录名]`:在当前文件夹下创建目录
- `rm[文件名]`删除指定文件，默认不能删除目录，需用 `-r`（递归）选项删除目录及其中所有内容（包括子目录和文件），如`rm -r dir`删除dir目录及其所有内容
- `-f`（force）强制删除，不提示确认，且忽略不存在的文件
- `-i`（interactive）删除前会逐一提示确认，需输入 `y` 或 `Y` 确认删除，其他键取消
- `rmdir[目录名]`:用于删除空目录
- `clear`:清屏
- `find[路径] - name "*.py"`:查找指定路径下扩展名是 .py 的文件，包括子目录
- 如果省略路径，表示在当前文件夹下查找
- 通配符在使用 find 命令时同时可用
- `cp [选项] 源文件/目录 目标文件/目录`:如`cp file.txt backup/`表示复制file.txt到当前目录的backup目录下（文件名不变），以 `/` 结尾表示目录，如`cp file.txt newfile.txt`表示复制file.txt到当前目录，并改名为newfile.txt或者`cp file.txt /home/users/docs/``cp` 默认只能复制文件，复制目录必须使用 `-r`（递归，recursive）选项
- `mv` 移动文件 ，如`mv file.txt dir/`  移动文件到目录  `mv old.txt new.txt`  重命名文件  `mv dir1 dir2`     重命名目录（或移动目录到其他位置）
- `cat`:查看文件全部内容，如`cat file.txt`输出file.txt的所有内容，加`-n`可以显示行号
- `more/less`分页查看大文件，如`more file.txt`按页显示，（空格翻页，q退出）`less file.txt`支持上下键滚动，搜索
- `vim` 并回车，会启动 Vim 编辑器的默认界面；若输入 `vim 文件名`（如 `vim test.txt`），则会打开指定文件（若文件不存在，会在保存时创建该文件）。
## 信息泄露理解
#### git泄露
Git 是开发者常用的代码版本控制工具，会在项目根目录生成一个隐藏的 `.git` 目录，用于存储代码的提交记录、分支信息、历史版本等核心数据（相当于代码仓库的 “数据库”）。
正常部署代码时，只需上传编译后的运行文件或源代码文件，**`.git` 目录完全不需要上传到服务器**。但如果开发者操作失误（如直接上传整个项目目录、使用错误的部署命令），导致 `.git` 目录暴露在服务器的 Web 可访问路径下，攻击者就能通过 URL 直接访问该目录（如 `http://xxx.com/.git/`），下载其中的文件并恢复出完整的代码（包括历史提交记录、敏感配置等），这就是 Git 泄露。
#### vim缓存
备份文件通常是开发者 / 服务器运维过程中生成的，因配置或操作失误暴露在 Web 路径下
常见的备份文件有很多，可以用python脚本遍历一下
```python
import requests  
url = input("请输入url:")  
li1=['web','website','backup','back','www','wwwroot','temp']  
li2=['tar','tar.gz','zip','rar']  
for i in li1:  
    for j in li2:  
        url_final=url+'/'+i+'.'+j  
        r=requests.get(url_final)  
        print(str(r)+"+"+url_final)#打印响应状态和最终url
```
最终响应码为200的为正确的备份文件名
vim泄露的缓存文件有
- `.文件名.swp`:编辑文件时实时生成（临时缓存）
- `.文件名.swn`:当`.swp`存在时，再次编辑生成（备用缓存）
- `.文件名.swo`:当`.swp`和`.swo`都存在时生成（三级缓存）
- `文件名~`:编辑并保存文件后，vim 自动生成的备份
## SVN泄露
原理类似与GIT泄露，都是开发者或运维人员在部署代码时，误将 SVN 版本控制工具生成的 **`.svn` 目录**（存储代码版本信息的核心目录）上传到服务器的 Web 可访问路径，导致攻击者可通过该目录下载并恢复完整代码仓库及历史版本。

## php执行系统命令的方法
- `system()`：执行系统命令，并输出结果。回显
- `exec()`：执行系统命令，返回最后一行结果（需用输出参数获取完整结果）。试了一下，不回显
- `shell_exec()`：执行系统命令，返回全部结果（字符串形式）。不回显
- `` `命令` ``（反引号）：与 `shell_exec()` 功能相同，例如  
```php
echo `whoami`;
```
这是回显的
- `passthru()`：执行系统命令，直接输出原始结果（适合二进制数据）。回显
- `pcntl_exec()`：执行指定程序（需 `pcntl` 扩展，直接替换当前进程）。不回显
- `popen`,例如`popen('ls -l', 'r');`执行ls-l,并且`r`读：从子进程接收输出，不回显
- `proc_open`  
## 绕过方式总结
#### 空格绕过
<  , <>, +,%20,%09，`$IFS$9`,`${IFS}`,`$IFS`,`$IFS$1`,`%0a` `%a0`可以替换空格，PHP 中用 `.` 连接字符串，可替代空格分隔变量或函数参数。
#### 点绕过
`.`，**如果是文件的话**，可以使用绝对路径从而避免出现`.`
还可以用 `$PWD`（当前目录绝对路径）替代 `.`:原命令：`./script.sh` → 绕过：`$PWD/script.sh`（`$PWD` 等价于当前目录绝对路径）。
**在命令执行中**，在 shell 中，`.` 是 `source` 命令的别名，用于在当前 shell 中执行脚本（如 `. ./env.sh` 加载环境变量），若 `.` 被过滤，可替换为 `source`：

原命令：`./env.sh` → 绕过：`source ./env.sh`（若 `source` 未被过滤）。
若路径中的 `.` 也被过滤：`source $PWD/env.sh`（结合 `$PWD` 替代当前目录）。
**代码注入中**：在 PHP 中，`.` 是字符串连接符（如 `"a"."b"` 拼接为 `"ab"`），若被过滤，可通过以下方式拼接字符串：  
```php
$a="fl";
$b="ag";
$str=$a$b;
```
还可以对`.`url加密为`%2E`  ，十六进制`\x2E` Unicode `\u002E`  
有些web服务器会对将文件的最后一个点后的扩展名解析，但可以加多个点，如：原文件名：`shell.php` → 绕过：`shell.php.xxx`（若 `.xxx` 不被拦截，且服务器仍解析为 PHP）。
#### 关键字符替换为空绕过方法
如果网页会将`flag` `cat` `ls` 或者其他重要字符替换为空，可以先观察是否使用循环语句，如果没有，则说明只替换一次，可以将关键词嵌套，如写成`flflagag`,删除掉一个flag,正好拼接成一个flag，或者加一个转义字符`fl\ag`
#### 大小写绕过法
如果题目只是黑名单了一个语法词汇的小写形式，可以将某些字母改为大写绕过，如:system改为System
## 某些语法被过滤怎么办
如cat被过滤可以用替代函数，如less/more/head/tail/nl/od/grep/printf/vi/ vim/ nano/tac等
ls被过滤可以用ll,tree,vdir,lsd,exa，tac替代
## 关键字符绕过
如果过滤目录分割符/，可以用`;`堆叠指令同时执行，例如`;cd 目录;cat 文件`避免了目录分割符，如果`|`被过滤了也可以这样绕过，如果`;`被过滤了，可以用%0a即换行符代替，flag被过滤了，可以用\转义符绕过`fl\ag`,或者文件名比较长时可以用`%09*`也就是tab键补齐，利用了linux的一个操作，cat等输出指令被过滤可以同类替换，如more,less等，还可以用base64加密输出，如`%0als%0acd$IFS%09*_is_here%0abase64$IFS%09*_3425453514235.php`避免使用cat等输出语句
