SSH（Secure Shell）22端口是Linux/Unix系统上最常见的**远程管理协议**。
## 主要用途
### 远程登录
可以直接在任何一台主机上拿到shell，前提是知道密码
```bash
ssh root@192.168.1.1
```
接下来输入密码，成功后就拿到shell了。
如果不知道密码，但是可以用某些方式给服务器写入公钥，
然后
```
ssh -i 你的私钥 root@题目IP
```
这样也可以拿到root权限。
### 安全文件传输
```bash
scp file.txt root@192.168.1.1:/tmp/
sftp root@192.168.1.1
```
可以通过 SSH 把内网服务"穿透"到本地访问。
