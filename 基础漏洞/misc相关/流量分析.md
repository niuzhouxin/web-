## wireshark使用
### 数据包筛选
#### 筛选ip
ip在`Internet Protocol Version 4`下的`Source`和`Destination`
```
ip.src == 源ip地址
```
或者选中一个源IP是筛选条件的数据包，找到`Internet Protocol Version 4`下的`Source`字段。
![](/image/311.png)
右击`Source`字段，再选择`作为过滤器应用` –-> 最后点击`选中`，就可筛选出该源IP的所有包了
#### 目的ip筛选
跟上面源IP筛选方法类似
选中一个源IP是筛选条件的数据包，找到`Internet Protocol Version 4`下的`Destination`字段。
右击`Destination`字段，再选择`作为过滤器应用` –-> 最后点击`选中`，就可筛选出该目的IP的所有包了
或者
```
ip.dst == 目标ip地址
```
#### mac地址筛选
mac地址在数据包详细信息里的`Ethernet II`下的`Source:`和`Destination`
```
eth.src == 00:11:22:33:44:55 筛选源ip地址
eth.dst ==A0:00:00:04:C5:84 筛选目标mac地址 
eth.addr==A0:00:00:04:C5:84 源或目的mac地址
```
#### 端口筛选
```
tcp.dstport == 80 筛选tcp协议的目标端口为80的流量包 
tcp.srcport == 80 筛选tcp协议的源端口为80的流量包 
udp.srcport == 80 筛选udp协议的源端口为80的流量包
```
#### 协议筛选
```
http 筛选http协议
tcp 筛选tcp协议
udp 筛选协议为udp的流量包
```
#### 包长度筛选
```
udp.length ==20 筛选长度为20的udp流量包 
tcp.len >=20 筛选长度大于20的tcp流量包 
ip.len ==20 筛选长度为20的IP流量包 
frame.len ==20 筛选长度为20的整个流量包
```
#### http请求筛选
```
请求方法为GET：http.request.method==“GET” 筛选HTTP请求方法为GET的 流量包 
请求方法为POST：http.request.method==“POST” 筛选HTTP请求方法为POST的流量包 
指定URI：http.request.uri==“/img/logo-edu.gif” 筛选HTTP请求的URL为/img/logo-edu.gif的流量包 
请求或相应中包含特定内容：http contains “FLAG” 筛选HTTP内容为/FLAG的流量包
```

这一关提示sql注入，那就过滤一下http包，![](/image/309.png)发现都是一些sql注入的操作，并且明显是用二分法进行盲注。

![](/image/310.png)
红色的框表示响应包的长度，一般就是通过响应长度显示是否成功的。
黄色的框表示盲注的是第几个字符。
绿色的表示当前测试的字符的ascii值相比较的值。
依次分析
- >100会回显长度1027，应该是错了
- >50回显长度1095，对了。
- >75回显1027，错了。
- >63回显1027，错了。
- >57回显1027，错了。
- >54回显1027，错了。
- >52回显1095，对了。
- >53回显1027，错了。
所以正确的ascii值是53。对应数字5，所以数据库长度是5。
所以正确结果是最后一个判断的数字。
所以直接找最后的flag了。
flag长度是38，一个一个找太麻烦，写脚本。
```python
import re #正则匹配  
import urllib.parse#url解码  
  
f = open("123.txt","r") #以只读"r"打开文件  
lines = f.readlines() #逐行读取原始内容  
datas = [] #创建空列表  
for line in lines:  
    datas.append(urllib.parse.unquote(line)) #url解码，方便匹配正则，添加到datas列表中  
lines = []  
for i in range (len(datas)):#遍历所有数据行  
    if datas[i].find("ascii(substr(((select concat_ws(char(94), flag)  from db_flag.tb_flag  limit 0,1)), 1, 1))>100") >0:#找到flag盲注开始的起点  
        lines = datas[i:]#从这一行开始切片  
        break#只寻找第一次出现的位置  
  
flag ={}#用来保存，例如flag[索引]==ASCII值  
  
macth1 = re.compile(r"substr\(\(\(select concat_ws\(char\(94\), flag\).*?limit 0,1\)\),\s*(\d+),\s*1\)\)>(\d+)")#r表示匹配原始字符串，\(转义括号，防止被python吞掉，.*?表示非贪婪匹配，中间尽量少吃，\s*匹配任意空白，(\d+)表示捕获组  
macth2 = re.compile(r'"HTTP","(\d+)","HTTP/1.1 200 OK')  
for i in range(0,len(lines),2):#步长为2，每次匹配两行  
    get1 = macth1.search(lines[i])#一个一个搜索  
    if get1:  
        key = int(get1.group(1))#key保存字符的位置  
        value = int(get1.group(2))#value保存字符的ascii编码  
        get2 = macth2.search(lines[i+1])#搜索第二行  
        if get2:  
            if int(get2.group(1)) >1000:#>1000表示匹配  
                value#ascii值为value  
        flag[key] = value  
  
f.close()  
result = ""  
for value in flag.values():  
    result += chr(value)#以字符的形式拼接  
print(result)
```
直接得到flag。

# USB HID Mouse parser (CTF version)  
# input : usbdata.txt  (tshark -e usb.capdata)  
# output: xy.txt       (mouse track points)  
  
posx = 0  
posy = 0  
  
with open('usbdata.txt', 'r') as fin, open('xy.txt', 'w') as fout:  
    for line in fin:  
        line = line.strip().lower()  
  
        # 至少需要 3 个字节：btn + x + y  
        if len(line) < 6:  
            continue  
  
        try:  
            btn = int(line[0:2], 16)#按十六进制，转换成十进制整数（按键位图）  
            x   = int(line[2:4], 16)#x位移  
            y   = int(line[4:6], 16)#y位移  
        except ValueError:  
            continue  
  
        # 8-bit signed conversion有符号数转换，因为USB HID用的是补码 7f->127 80->-128 ff-> -1 Python 默认把 hex 当 无符号数，必须手动修正。  
        if x > 127:  
            x -= 256  
        if y > 127:  
            y -= 256  
  
        posx += x  
        posy += y  
  
        # 只在有按键时记录（CTF 通常这样）  
        if btn != 0:  
            fout.write(f"{posx} {posy}\n")

## ICS流量分析
### 任务 1：谁把阀门打开了？2.00 分
找到 Modbus 打开阀门指令的相关信息。
提交格式：flag{0xtransaction_id_0xfunction_code_0xcoil_address}
在工业控制系统中，“打开阀门”通常对应于对 **线圈（Coil）** 进行“写”操作。
常见功能码
```
1：读线圈 
2：读离散输入 
3：读保持 
4：读输入 
5：写单个线圈 
6：写单个保持 
15：写多个线圈 
16：写多个保持
```
过滤modbus和功能码为5的流量
```
(modbus and modbus.func_code == 5 )
```
对于功能码 5，**`0xff00`** 代表“置为 ON”（打开阀门），**`0x0000`** 代表“置为 OFF”。
进一步过滤
```
(modbus and modbus.func_code == 5 ) &&(modbus.data == ff00)
```
发现还是过滤出了许多流量，那就按时间排序，找最早打开的流量包。
![](/image/333.png)
其中Transaction Identifier就是transaction_id ，Function Code就是function_code也就是5，Reference Number 就是coil_address，只不过提交时要转为十六进制。
最终flag`flag{0x3c4d_0x05_0x0015}`
### 任务 2：被读取的 NodeId2.00 分
找到通过 OPC UA 协议读取的 NodeId。
提交格式：flag{ns=X;s=Path/To/Node}
这一关要过滤OPC UA协议，并且是被读取的，因为OPC UA默认是4840端口，所以过滤器是
```
tcp.port == 4840 && tcp contains "ReadRequest"
```
过滤出来好多包，依然是按时间排序，打开最早的那个包。内容是
```
ReadRequest;NodeId=ns=2;s=Valve/Status;MaxAge=0
```
所以flag`flag{ns=2;s=Valve/Status}`
