在阿里云文档中对于元数据的介绍，实例元数据（metadata）包含了弹性计算云服务器实例在阿里云系统中的信息（其中信息包括了实例ID、IP地址、网卡MAC地址、操作系统类型等信息。实例标识包括实例标识文档和实例标识签名，所有信息均实时生成，常用于快速辨别实例身份），你通过可以在运行中的实例内方便地查看实例元数据，并基于实例元数据配置或管理实例。
## 元数据metadata的查看
各个云厂商都有自己的元数据metadata查看，下面的部分云厂商的元数据访问地址

| 云厂商     | 元数据地址                              | 特殊说明        |
| ------- | ---------------------------------- | ----------- |
| AWS     | `http://169.254.169.254/`          | 支持IMDSv2    |
| 华为云     | `http://169.254.169.254/`          | OpenStack体系 |
| 微软Azure | `http://169.254.169.254/`          | 需要特定Header  |
| 阿里云     | `http://100.100.100.200/`          | 独立地址        |
| 腾讯云     | `http://metadata.tencentyun.com/`  | 域名形式        |
| 谷歌云     | `http://metadata.google.internal/` | 域名形式        |
AWS/通用路径
```
# 查看所有可用版本
/latest/meta-data/

# 基本信息
/latest/meta-data/instance-id        # 实例ID
/latest/meta-data/local-ipv4         # 内网IP
/latest/meta-data/public-ipv4        # 公网IP
/latest/meta-data/hostname           # 主机名
/latest/meta-data/local-hostname     # 本地主机名
/latest/meta-data/placement/region   # 所在地区

# 网络信息
/latest/meta-data/network/interfaces/macs/  # 网卡MAC列表

# 安全组
/latest/meta-data/security-groups

# 最敏感的路径 —— IAM临时凭证
/latest/meta-data/iam/security-credentials/
/latest/meta-data/iam/security-credentials/{角色名}
# 返回 AccessKeyId + SecretAccessKey + Token

/latest/user-data
# 返回实例启动时传入的初始化脚本
# 常见内容：安装软件、设置密码、写入密钥等
```
## 判断云环境类型
### 看主机名后缀
```
# 访问
/latest/meta-data/local-hostname

# 返回
suctf2026-0009.novalocal
              ↑
         novalocal 是 OpenStack Nova 计算服务的默认域名后缀
         这是最直接的特征
```
各云环境识别特征汇总

| 特征    | AWS             | 阿里云           | 华为云/OpenStack       | 腾讯云            |     |
| ----- | --------------- | ------------- | ------------------- | -------------- | --- |
| 主机名后缀 | `.ec2.internal` | `.internal`   | `.novalocal`        | `.internal`    |     |
| 专属路径  | `/latest/`      | `/latest/`    | `/openstack/`       | `/latest/`     |     |
| 地域格式  | `us-east-1`     | `cn-hangzhou` | `cn-southwest-2`    | `ap-guangzhou` |     |
| 凭证路径  | `/iam/`         | `/ram/`       | 无标准凭证路径             | `/cam/`        |     |
| AMI信息 | 有 `ami-id`      | 有 `image-id`  | `metering.image_id` | 有 `image-id`   |     |
### 看安全组命名风格
```
# 访问
/latest/meta-data/security-groups

# 返回
SUCTF2026
Sys-WebServer
# 华为云/OpenStack 的安全组命名风格
```
### 访问专属路径
```
# AWS 没有这个路径，OpenStack 特有
/openstack/latest/meta_data.json

# 如果返回数据而不是404 → 确认是OpenStack
```

## 各个云环境特有的路径
### OpenStack / 华为云路径
**meta_data.json**
```json
GET /openstack/latest/meta_data.json
# 返回完整JSON，包含：
{
  "uuid": "实例UUID",
  "hostname": "主机名",
  "name": "实例名称",
  "availability_zone": "可用区",
  "region_id": "地域",
  "project_id": "项目ID",
  "meta": {
    "vpc_id": "VPC ID",
    "os_type": "Linux",
    "image_name": "Ubuntu 22.04",
    "charging_mode": "计费模式"
  }
}
```
**network_data.json**
```json
GET /openstack/latest/network_data.json
# 返回：
{
  "links": [...],       # 网卡信息
  "networks": [
    {
      "ip_address": "10.0.1.23",
      "network_id": "...",
      "type": "ipv4"
    }
  ],
  "services": [
    {"address": "10.0.0.1", "type": "dns"}  # 内网DNS地址
  ]
}
```
**vendor_data**
```
GET /openstack/latest/vendor_data.json
# 云厂商自定义数据，可能包含：
# - 证书
# - 内部服务地址
# - 初始配置
```
### 阿里云路径
```
/latest/meta-data/instance/instance-id
/latest/meta-data/instance/image-id
/latest/meta-data/ram/security-credentials/   # 类似AWS的IAM凭证
/latest/meta-data/ram/security-credentials/{角色名}
```
### 腾讯云路径
```
/latest/meta-data/instance-id
/latest/meta-data/region
/cam/security-credentials/                    # CAM角色凭证
/cam/security-credentials/{角色名}
```
### 谷歌云还需要特殊header
```
# 谷歌云必须带这个Header，否则返回403
GET http://metadata.google.internal/computeMetadata/v1/
Metadata-Flavor: Google
```

### Azure 也需要特殊 Header
```
GET http://169.254.169.254/metadata/instance  
Metadata: true
```
