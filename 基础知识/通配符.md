在 Linux 命令行中，**通配符（Wildcards）** 是用于匹配文件名或路径的特殊字符，能快速筛选、操作符合规则的文件 / 目录，常用于 `ls`、`rm`、`cp`、`mv` 等命令中。常见的通配符有以下几种：

### 1. `*`：匹配任意长度的任意字符（包括空字符）

- 作用：代表**0 个或多个任意字符**，是最常用的通配符。
- 示例：
    
    bash
    
    ```bash
    ls *.txt       # 列出当前目录所有以 .txt 结尾的文件（如 a.txt、test123.txt）
    ls doc*        # 列出所有以 doc 开头的文件/目录（如 doc、document.pdf、doc_2023）
    ls *report*    # 列出文件名中包含 report 的所有文件（如 daily_report.txt、finalreport.pdf）
    rm *.log       # 删除所有以 .log 结尾的文件
    ```
    

### 2. `?`：匹配单个任意字符

- 作用：仅匹配**1 个任意字符**（必须有一个字符，不能空）。
- 示例：
    
    bash
    
    ```bash
    ls file?.txt   # 匹配 file 后接1个字符的 .txt 文件（如 file1.txt、fileA.txt，但不匹配 file.txt 或 file12.txt）
    ls ?.sh        # 匹配文件名只有1个字符且以 .sh 结尾的文件（如 a.sh、3.sh）
    ```
    

### 3. `[]`：匹配括号内的任意单个字符

- 作用：仅匹配**括号中列出的字符中的一个**，支持字符范围（如 `a-z`、`0-9`）。
- 示例：
    
    bash
    
    ```bash
    ls file[123].txt  # 匹配 file1.txt、file2.txt、file3.txt
    ls [abc].pdf      # 匹配 a.pdf、b.pdf、c.pdf
    ls [0-9].log      # 匹配 0.log、1.log ... 9.log（单个数字）
    ls [a-z].sh       # 匹配 a.sh、b.sh ... z.sh（单个小写字母）
    ls [A-Za-z].txt   # 匹配单个大小写字母开头的 .txt 文件
    ```
    

### 4. `[!]` 或 `[^]`：匹配不在括号内的任意单个字符

- 作用：与 `[]` 相反，匹配**不在括号中列出的字符**。
- 示例：
    
    bash
    
    ```bash
    ls file[!123].txt  # 匹配 file 后接的字符不是 1、2、3 的 .txt 文件（如 file4.txt、fileA.txt）
    ls [!a-z].pdf      # 匹配文件名首字符不是小写字母的 .pdf 文件（如 1.pdf、A.pdf、_data.pdf）
    ls [^0-9].log      # 等同于 [!0-9].log，匹配首字符不是数字的 .log 文件
    ```
    

### 5. `{}`：生成序列（非通配符，是 Shell 扩展）

- 作用：虽然不是严格意义上的通配符，但常用于批量生成文件名或路径，支持列表和范围。
- 示例：
    
    bash
    
    ```bash
    touch file{1,2,3}.txt  # 同时创建 file1.txt、file2.txt、file3.txt
    cp report{,.bak}       # 复制 report 为 report.bak（备份常用）
    mkdir dir{1..5}        # 创建 dir1、dir2、dir3、dir4、dir5（范围生成）
    ls log{.txt,.log}      # 列出 log.txt 和 log.log（若存在）
    ```
