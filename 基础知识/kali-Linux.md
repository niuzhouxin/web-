## 基本指令
- `ls`:查看当前文件夹下的内容，加`-a`，表示显示所有内容，包括隐藏文件，加`-l`表示以列表的形式列出文件，`ls 目录名`列出目录下的所有文件目录，`ls /`列出根目录下所有文件
- `pwd`:查看当前所在文件夹
- `cd[目录名]`:切换文件夹，`cd ..` 切换到上一级目录
- `touch[文件名]`如果**文件不存在**，新建文件,如果文件已存在，`touch` 会默认更新其 **访问时间（atime）** 和 **修改时间（mtime）** 为当前系统时间。
- `mkdir[目录名]`:在当前文件夹下创建目录
- `rm[文件名]`删除指定文件，默认不能删除目录，需用 `-r`（递归）选项删除目录及其中所有内容（包括子目录和文件），如`rm -r dir`删除dir目录及其所有内容
- `-f`（force）强制删除，不提示确认，且忽略不存在的文件
- `-i`（interactive）删除前会逐一提示确认，需输入 `y` 或 `Y` 确认删除，其他键取消
- `rmdir[目录名]`:用于删除空目录
- `clear`:清屏
- `find[路径] - name "*.py"`:查找指定路径下扩展名是 .py 的文件，包括子目录
- 如果省略路径，表示在当前文件夹下查找
- 通配符在使用 find 命令时同时可用
- `cp [选项] 源文件/目录 目标文件/目录`:如`cp file.txt backup/`表示复制file.txt到当前目录的backup目录下（文件名不变），以 `/` 结尾表示目录，如`cp file.txt newfile.txt`表示复制file.txt到当前目录，并改名为newfile.txt或者`cp file.txt /home/users/docs/``cp` 默认只能复制文件，复制目录必须使用 `-r`（递归，recursive）选项
- `mv` 移动文件 ，如`mv file.txt dir/`  移动文件到目录  `mv old.txt new.txt`  重命名文件  `mv dir1 dir2`     重命名目录（或移动目录到其他位置）
- `cat`:查看文件全部内容，如`cat file.txt`输出file.txt的所有内容，加`-n`可以显示行号
- `more/less`分页查看大文件，如`more file.txt`按页显示，（空格翻页，q退出）`less file.txt`支持上下键滚动，搜索
- `sudo su`切换到root权限
- `ctrl+c`退出编辑界面,再输`:wq`用来保存文件，`:%d`删除文件全部内容
- `mktemp -d`在系统默认临时目录（通常是 `/tmp`）中创建一个唯一的临时目录，返回目录的绝对路径。示例输出`/tmp/tmp.8Z7x9Y2k5s`
## 小技巧
- `ctrl + shift + =` **放大**终端窗口的字体显示
- `ctrl + -` **缩小**终端窗口的字体显示
- 在敲出 `文件` ／ `目录` ／ `命令` 的前几个字母之后，按下 tab 键
- 如果输入的没有歧义，系统会自动补全
- 如果还存在其他 `文件` ／ `目录` ／ `命令` ，再按一下 tab 键，系统会提示可能存在的命令
- 按 `上` ／ `下` 光标键可以在曾经使用过的命令之间来回切换
- 如果想要退出选择，并且不想执行当前选中的命令，可以按 `ctrl + c`
## 注意
有些操作需要管理员权限才能执行，执行时在指令前加上`sudo`来获取root权限，输入指令`sudo -i`来登录root
## 普通用户与root用户
- **普通用户**：
仅拥有对自己家目录（如 `/home/用户名`）内文件的完全操作权限（读、写、执行），对系统级文件（如 `/etc/`、`/bin/`、`/usr/` 等）通常只有**读权限**，无法修改系统配置、安装全局软件、删除系统文件或管理其他用户。
例如：普通用户不能直接执行 `rm /bin/ls`（删除系统命令）、`useradd 新用户`（创建用户）等操作。
- **root 用户**：
拥有系统**最高权限**，可以操作任何文件、修改任何配置、管理所有用户（创建 / 删除 / 修改）、安装卸载软件、重启关机、访问所有硬件设备等，不受系统权限限制。
例如：root 可以直接删除 `/etc/passwd`（用户配置文件）、修改系统内核参数等。
## 文件权限/目录权限
Linux 中每个文件 / 目录的权限都包含三部分，分别对应三类用户：
1. **所有者（User）**：文件 / 目录的创建者或指定的拥有者。
2. **所属组（Group）**：文件 / 目录所属的用户组（一个用户可属于多个组）。
3. **其他用户（Others）**：既不是所有者，也不属于所属组的用户。
通过 `ls -l` 命令可查看权限，例如：
```
ls -l file.txt
# 输出：-rw-r--r-- 1 user group 0 Oct 19 10:00 file.txt
```
- 第一个字符 `-` 表示类型（`-` 是文件，`d` 是目录）。
- 接下来的 `rw-r--r--` 就是权限：
- 前 3 位 `rw-`：所有者权限（读r、写w，无执行x）。
- 中间 3 位 `r--`：所属组权限（只读）。
- 后 3 位 `r--`：其他用户权限（只读）。
所以`drwxr-xr-x` `d`中表示是目录,`rwx`表示所有者又读写执行权限，`r-x`表示所属组有读权限和执行权限，无写权限，`r-x`表示其他用户有读权限和执行权限
## linux敏感文件目录
#### /root
- root 用户（超级用户）的家目录（主目录）。
- 类似于普通用户的 `/home/用户名` 目录，用于存放 root 用户的个人配置文件、脚本、临时数据等。例如，root 用户的 `.bashrc`（命令行配置）、`.ssh`（SSH 密钥）等文件会存放在这里。
- 默认只有 root 用户拥有读写和执行权限（普通用户无法访问），确保管理员数据的安全性。
#### /bin
- `binary`（二进制文件）的缩写，存放系统**核心可执行命令**的目录。
- 包含所有用户（包括普通用户）都能执行的基础命令，这些命令在系统启动阶段（甚至根文件系统挂载前）就可能被使用，是系统运行的必备工具。常见命令如 `ls`（列出目录）、`cp`（复制文件）、`mv`（移动文件）、`rm`（删除文件）、`bash`（默认 shell）等都位于此目录。目录中的命令多为二进制程序（可直接执行），且属于系统基础组件，不可随意删除或修改，否则会导致系统功能异常。
#### /proc
- `process`（进程）的缩写，是一个**虚拟文件系统**（不占用实际磁盘空间，内容存在于内存中）。
- 实时反映系统内核状态、进程信息和硬件信息，提供了用户空间与内核空间交互的接口。例如：`/proc/cpuinfo` 显示 CPU 信息，`/proc/meminfo` 显示内存使用情况，`/proc/[进程ID]/` 目录（如 `/proc/1234/`）包含进程 ID 为 1234 的进程详细信息（如命令行参数、环境变量、打开的文件描述符等）。
- 内容动态生成（随系统状态变化），用户可通过读取这些文件获取系统实时数据，但修改部分文件（如内核参数相关文件）需 root 权限，且可能影响系统运行。
#### /etc/passwd
- 系统用户账号信息配置文件（`passwd` 即 “密码”，但该文件并不存储实际密码）。
- 记录系统中所有用户的基本信息，每行对应一个用户，格式为：
```
用户名:密码占位符:UID:GID:用户描述:家目录:默认shell  
```
例如：`root:x:0:0:root:/root:/bin/bash` 表示：
- 用户名 `root`，密码占位符 `x`（实际密码存于 `/etc/shadow`），UID（用户 ID）为 0，GID（所属组 ID）为 0，描述为 `root`，家目录为 `/root`，默认 shell 为 `/bin/bash`。
- 默认所有用户可读（便于系统识别用户身份），但只有 root用户可修改，确保用户信息的一致性。
#### /boot/
存放系统启动相关文件（内核 `vmlinuz`、启动引导程序 `grub` 配置等），篡改可能导致系统无法启动或植入恶意代码。
#### /sys/
与硬件设备和内核参数相关的虚拟文件系统，部分文件可直接修改内核行为（如 `sysctl` 配置）。
