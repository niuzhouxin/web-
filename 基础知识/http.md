- `Host`：指定目标服务器的域名或 IP（如 `Host: example.com`），用于服务器在多站点部署时识别具体站点。
- `User-Agent`：标识客户端类型（如浏览器、脚本），例如 `Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/118.0.0.0`（表示 Windows 系统的 Chrome 浏览器）。
- `Content-Type`：仅在 `POST/PUT` 等有请求体的方法中使用，指定请求体的数据格式，例如：
    - `application/x-www-form-urlencoded`：普通表单数据（如 `name=test&age=18`）。
    - `multipart/form-data`：文件上传时使用。
    - `application/json`：JSON 格式的数据。
- `Cookie`：携带客户端存储的 Cookie 信息（如登录凭证），例如 `Cookie: sessionid=abc123; username=test`。
- `Referer`：标识当前请求是从哪个页面跳转过来的（如从  `https://a.com` 跳转到 `https://b.com`，则 `Referer: https://a.com`）。

# 3. 请求体（Request Body）：传递请求的核心数据（可选）

请求体是可选模块，仅在 `POST/PUT` 等需要向服务器提交数据的方法中存在，用于承载具体数据（如表单内容、文件二进制数据）。

- 数据格式由 `Content-Type` 请求头决定（如 `application/x-www-form-urlencoded` 格式的请求体为 `name=test&age=18`，`application/json` 格式为 `{"name":"test","age":18}`）。
- `GET` 方法没有请求体，参数通过 URL 的 “查询字符串”（`?` 后的部分）传递。

# 4. 空行（Blank Line）：分隔请求头与请求体

请求头和请求体之间必须有一个 “空行”（仅包含换行符 `\n` 或回车 + 换行 `\r\n`），这是 HTTP 协议的强制规定 —— 用于告诉服务器 “请求头已结束，接下来是请求体（若有）”。

若缺少空行，服务器可能无法正确解析请求（如把请求体内容当作请求头处理）。

# 响应码
## 成功类响应码(2xx)
**200**:请求成功，服务器返回内容,目录扫描时返回 200，说明路径存在（如`/admin`后台、`/wp-config.php`配置文件）；2. 漏洞利用后返回 200，可能表示攻击成功（如文件上传后访问木马文件返回 200）。
**201**:请求成功且创建资源.文件上传漏洞测试时，返回 201 可能表示恶意文件已成功上传（需进一步访问文件路径验证）。
**204**:成功但无返回内容.部分 API 接口或 AJAX 请求中出现，需结合其他信息判断（如爆破密码时，204 可能与 200 等价，代表登录成功）。
## 重定向类响应码(3xx)
**301**:永久重定向.1. 访问`http://目标IP`跳转到`https://`或其他域名，需调整攻击目标地址；2. 目录扫描时，`/admin`重定向到`/admin/login`，说明后台路径存在且需登录。
**302**:临时重定向.1. 登录失败时跳转到错误页面（可通过 Burp 分析跳转逻辑，判断账号密码是否正确）；2. 未登录访问后台时，重定向到登录页（确认后台路径有效）。
**307**:临时重定向（保留请求方法）
## 客户端错误类响应码（4xx）
**400**:请求格式错误
**401**:未授权（需认证）
**403**:服务器拒绝访问,1. 路径存在但无权限访问（如`/root/`、`/etc/passwd`），可尝试目录遍历、文件包含漏洞绕过；2. 服务器配置了访问控制（如 IP 白名单），需寻找代理或跳板机。
**404**:资源不存在,1. 目录扫描时返回 404，说明路径无效（可排除该方向）；2. 部分网站自定义 404 页面（实际返回 200），需结合页面内容判断（避免误判）。
**405**：请求方法不允许
**408**：请求超时
**429**：请求过于频繁
## 服务器错误类响应码（5xx）
**500**：服务器内部错误。1. SQL 注入、命令注入等漏洞触发时返回（说明 payload 可能有效，需进一步优化）；2. 服务器代码存在 bug（如配置文件错误），可尝试探测敏感信息泄露。
**502**：网关错误。1. 目标服务器是反向代理（如 Nginx+Tomcat），后端服务宕机或配置错误；2. 部分 WAF 拦截恶意请求后返回 502，需调整 payload 绕过。
**503**：服务不可用，1. 服务器维护、过载或宕机（需等待恢复）；2. 漏洞利用导致服务崩溃（说明 payload 可能过强，需简化测试）。
**504**：网关超时。1. 后端服务响应过慢（如数据库查询超时）；2. 网络延迟导致请求未到达后端，需检查网络连通性。
**优先关注200、301、302、401、403 响应码：这些代码代表路径存在（404 直接排除）。**
